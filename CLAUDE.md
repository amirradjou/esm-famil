# esm-famil

Online multiplayer اسم فامیل (Persian Scattergories): a pnpm workspace with a shared rules
package, a socket.io game server and a React client.

## Commands
| Task | Command |
|------|---------|
| Install deps | `pnpm install` |
| Run | `pnpm dev` |
| Test | `pnpm test` |
| Lint + format | `pnpm lint` |

## Conventions
- See global preferences in `~/.claude/CLAUDE.md` (conventional commits, feature branches, etc.).
- Run tests and lint before declaring work done.
